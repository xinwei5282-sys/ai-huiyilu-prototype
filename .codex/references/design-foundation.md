# 云忆项目设计规范入口

项目级 UI 设计规范已单独维护在：

- [`docs/UI设计规范.md`](../../docs/UI设计规范.md)

后续颜色、组件、状态和页面视觉规则，以 `docs/UI设计规范.md` 为唯一真源。

## 当前规范重点

- 视觉方向：温暖、安静、有陪伴感、低压力、成果感。
- 颜色系统：暖阳奶油 + 深棕文字 + 低饱和陶土橙 + 松绿色完成态。
- 禁止：强任务压力、后台工具感、科技蓝紫主色、大面积强红橙按钮、大面积纯白底。

如需调整项目 UI 标准，先更新 `docs/UI设计规范.md`，再同步到 `prototype-v17.html` 和设计稿。
