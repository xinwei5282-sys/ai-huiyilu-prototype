# 云忆项目 UI 设计规范（Design Foundation）

> 本文件是云忆项目的 UI 设计基础规范。所有原型、设计稿、客户演示图和后续前端实现，涉及颜色、组件状态、视觉层级时，以本文件为准。
> 当前实现参考：`prototype-v17.html`。

---

## 1. 产品视觉方向

- **产品名称**：云忆 · 生命故事
- **产品定位**：帮助长辈和家人一起记录生命故事，并逐步沉淀为故事、章节和成书成果。
- **核心气质**：温暖、安静、有陪伴感、低压力、成果感。
- **设计关键词**：暖阳、书页、相册、陶土、木色、家人陪伴。
- **不应出现的气质**：强任务压力、工具后台感、促销感、冷科技感、养老院式厚重感。

### 1.1 颜色策略

云忆不使用高饱和科技蓝/紫，也不使用大面积强红橙。整体以暖奶油底色承载内容，以深棕保证文字可读，以低饱和陶土色表达行动与情绪，以松绿色表达完成、保存、安心。

## 2. 颜色系统

### 2.1 基础色板

| Token | 色值 | 名称 | 用途 |
|---|---:|---|---|
| `--cream` | `#FAF6F0` | 暖阳奶油 | 页面默认背景、浅底 |
| `--cream-2` | `#FFFBF5` | 纸页白 | 次级按钮、输入框、浅卡片 |
| `--card` | `#FFFFFF` | 卡片白 | 内容卡片、弹层、浮层 |
| `--paper-line` | `#EFE1D2` | 纸页分割线 | 输入框边框、轻分割线 |
| `--line` | `#EDE4D8` | 常规线 | 列表分隔、外框线 |

### 2.2 文字色

| Token | 色值 | 名称 | 用途 |
|---|---:|---|---|
| `--brown-h` | `#1E1712` | 标题深棕 | 大标题、重要标题、主按钮文字 |
| `--brown` | `#2A2019` | 正文棕黑 | 正文、列表标题、主要信息 |
| `--brown-500` | `#8A6F5C` | 温暖中棕 | 辅助标题、提示、低强调 |
| `--text` | `#2A2019` | 主要文字 | 默认正文 |
| `--text-2` | `#7C6B5E` | 次级文字 | 描述、说明、次级信息 |
| `--text-3` | `#A0917F` | 弱文字 | 时间、占位、弱提示 |

**文字规则**：
- 大标题优先使用 `--brown-h`，避免纯黑。
- 正文使用 `--text`，不可使用低对比灰。
- 说明文字最低使用 `--text-2`；`--text-3` 只用于非常弱的信息，不用于关键操作说明。

### 2.3 品牌与行动色

| Token | 色值 | 名称 | 用途 |
|---|---:|---|---|
| `--gold` | `#D9663F` | 陶土橙 | 品牌强调、选中态、进度、关键图标 |
| `--gold-deep` | `#B44A2A` | 深陶土 | 链接、重点标签、激活状态 |
| `--gold-btn1` | `#EE8B5D` | 暖橙亮面 | 渐变按钮亮端，少量使用 |
| `--gold-btn2` | `#D9663F` | 暖橙主面 | 渐变按钮主端，少量使用 |
| `--gold-ink` | `#B44A2A` | 陶土文字 | 暖色背景上的强调文字 |

**行动色规则**：
- `--gold` 是强调色，不是大面积背景色。
- 首页、采访、追问等高频页面的主按钮应优先使用低饱和陶土/纸感色，而不是大面积强橙渐变。
- 强橙渐变只用于少数关键确认、升级、状态徽章，不用于整页多处重复。

### 2.4 陪伴与完成色

| Token | 色值 | 名称 | 用途 |
|---|---:|---|---|
| `--green` | `#4C7A5C` | 松绿色 | 保存成功、已完成、安心提示 |
| `--green-2` | `#4C7A5C` | 松绿色强调 | 完成标签、采纳、家人补充确认 |
| `--green-700` | `#3C6249` | 深松绿 | 深色成功文字 |
| `--success` | `#4C7A5C` | 成功色 | 成功状态 |
| `--success-bg` | `#E7F0E8` | 成功浅底 | 成功提示背景 |

**绿色规则**：
- 绿色只表达“已保存 / 已完成 / 已采纳 / 安心可继续”。
- 不用于主 CTA，避免和记录入口竞争。

### 2.5 状态色

| Token | 色值 | 名称 | 用途 |
|---|---:|---|---|
| `--progress` | `#D9663F` | 记录进度 | 录音中、处理中、当前进度 |
| `--progress-bg` | `#FDE7D6` | 进度浅底 | 进度提示背景 |
| `--danger` | `#B23A2E` | 危险红 | 删除、错误、不可逆提醒 |
| `--danger-bg` | `#F6E1DA` | 危险浅底 | 错误提示背景 |
| `--error` | `#B94A3A` | 表单错误 | 表单错误、失败状态 |
| `--info` | `#4E6E78` | 信息蓝灰 | 中性信息、系统提示 |
| `--info-bg` | `#DCE7E8` | 信息浅底 | 信息提示背景 |

**状态规则**：
- 错误/危险必须使用红系，不用橙色冒充。
- 录音、转写、生成中使用 `--progress`，但面积要克制。
- 网络慢、权限提示等中性场景优先使用 `--info` 或暖棕中性色。

## 3. 推荐配色组合

### 3.1 页面背景

```css
background:
  radial-gradient(120% 60% at 100% 0%, rgba(249,197,150,.12), transparent 55%),
  var(--cream);
```

用于讲述页、我的页、普通内容页。保持暖、轻、低压力。

### 3.2 纸页卡片

```css
background: linear-gradient(180deg, #FFFCF6 0%, #FFF5E8 100%);
border: 1px solid rgba(124, 86, 48, .13);
box-shadow: 0 8px 24px -14px rgba(150, 74, 42, .30);
```

用于故事卡、追问卡、书籍相关卡片。适合表达“书页 / 回忆册”。

### 3.3 主入口按钮（低压版）

```css
background: linear-gradient(138deg, #F3D5B8 0%, #DDA77E 54%, #BD7654 100%);
color: var(--brown-h);
border: 1px solid rgba(143, 79, 46, .18);
```

用于首页“按问题慢慢讲”这类默认主路径。避免使用高饱和橙红。

### 3.4 强行动按钮（谨慎使用）

```css
background: linear-gradient(180deg, var(--gold-btn1), var(--gold-btn2));
color: #fff;
```

只用于强确认、升级购买、最终提交等少量场景。

### 3.5 成功提示

```css
background: var(--success-bg);
color: var(--green-700);
border: 1px solid rgba(76, 122, 92, .18);
```

用于自动保存、采纳成功、生成完成。

## 4. 颜色使用分层

### 4.1 60 / 30 / 10 原则

- **60% 暖奶油底色**：`--cream`、`--cream-2`、纸页渐变。
- **30% 深棕文字与木色结构**：`--brown-h`、`--brown`、`--brown-500`。
- **10% 陶土橙和松绿色**：行动、强调、完成状态。

### 4.2 页面类型用色

| 页面类型 | 主基调 | 强调色 | 注意 |
|---|---|---|---|
| 首页 | 人像暖光 + 奶油底 | 低饱和陶土 | 入口不做促销感 |
| 采访录音页 | 暖纸页 + 低压中性色 | 陶土进度色 | 录音状态明确但不紧张 |
| 追问页 | 纸页卡片 | 陶土主按钮、松绿完成 | 主按钮固定但不过度压迫 |
| 故事小结 | 书页白、暖米色 | 陶土标题、松绿保存 | 强化成果感 |
| 书房 | 木色、玻璃、书籍色 | 陶土少量点缀 | 不做后台列表感 |
| 我的/账户 | 奶油底 + 白卡 | 陶土入口、松绿状态 | 信息清楚、少装饰 |

## 5. 禁用规则

1. **禁止大面积纯白底**：除内容卡片外，不要整页 `#FFFFFF`。
2. **禁止纯黑文字**：使用 `--brown-h` 或 `--brown`。
3. **禁止科技蓝/紫作为主色**：会偏离生命故事和家人陪伴气质。
4. **禁止多个高饱和橙色按钮同时出现**：会产生促销和任务压力。
5. **禁止低对比浅灰正文**：老人用户和客户演示都需要清晰可读。
6. **禁止红色表达普通进度**：红色只用于危险、错误、不可逆。
7. **禁止一页内引入新的未命名颜色**：如确需新增，先补充本规范。

## 7. 组件颜色规则

### 7.1 主按钮

- 默认使用低饱和陶土纸感方案。
- 文字优先深棕，不强制白字。
- 只有强确认场景才允许使用 `--gold-btn1 -> --gold-btn2` 渐变白字。

### 7.2 次按钮

- 背景：`rgba(255,255,255,.62)` 或 `--cream-2`
- 边框：`rgba(120,90,60,.12)` 或 `--paper-line`
- 文字：`--brown`
- 图标：`--gold-deep` 或 `--brown-500`

### 7.3 卡片

- 内容成果卡：纸页渐变，使用暖白而不是纯白。
- 系统信息卡：`--cream-2` + `--line`。
- 弹窗/底部弹层：`--card` 或 `#FFFCF6`，不可使用冷灰背景。

### 7.4 标签 / 徽章

- 进行中：`--progress-bg` + `--gold-deep`
- 已完成：`--success-bg` + `--green-700`
- 待处理：浅暖底 + `--brown-500`
- 危险/错误：`--danger-bg` + `--danger`

### 7.5 Tab / 当前选中

- 选中图标：`--gold-deep`
- 未选中图标：`--text-3`
- 分割线：`--line`
- 底栏背景：`rgba(255,255,255,.92)`，允许轻微 blur。

## 8. 可读性与无障碍

- 关键正文最小 16px。
- 辅助文字最小 14px；若低于 14px 只允许用于角标、时间、非关键注释。
- 文字与背景对比必须优先保证可读，不为了“淡雅”牺牲识别。
- 彩色背景上的白字只用于深色或足够饱和背景；浅陶土背景上应使用深棕字。
- 点击热区不小于 44px，高频入口建议 60px 以上。

## 9. 首页颜色专项

首页是云忆的第一印象，颜色必须服务于“家人在等你继续讲”的心智。

- 人像照片作为情绪背景，文字区域必须加暖光遮罩保证可读。
- `晓晓看过您的故事` 使用暖白胶囊，不使用系统蓝通知样式。
- `下午好，秀英` 使用深棕大字，不使用橙色标题。
- 主入口 `按问题慢慢讲` 使用低饱和陶土纸签，不使用强红橙促销按钮。
- `随便讲一段`、`拿照片来讲` 使用浅白/奶油底，保持等宽和轻层级。
- 首页不要新增未命名装饰色；如需要光晕，只允许使用陶土色低透明度。

## 10. 设计检查清单

提交 UI 前检查：

- [ ] 是否仍符合“温暖、安静、有陪伴感、低压力”。
- [ ] 是否使用本文件中的颜色 token。
- [ ] 是否有未命名的新颜色。
- [ ] 主按钮是否过于强橙/促销化。
- [ ] 状态色语义是否正确：绿色=完成，红色=危险，橙色=进度/强调。
- [ ] 文字对比是否足够，辅助文案是否可读。
- [ ] 页面是否出现大面积纯白或冷灰。
- [ ] 首页、采访、追问、书房之间的暖色系统是否一致。
- [ ] 已渲染检查关键页面，而不是只看代码。
