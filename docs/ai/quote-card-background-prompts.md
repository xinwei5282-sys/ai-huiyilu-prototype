# 金句卡 AI 背景提示词

## 使用边界

- 背景必须同时理解金句内容和金句所在文章的语境，不能只套固定怀旧模板。
- 采用两阶段生成：文本模型先提炼画面语境，图片模型再生成背景。
- 不把完整文章直接发送给图片模型；图片模型只接收结构化画面信息和金句。
- AI 不处理用户头像。应用端负责叠加头像、金句、姓名、品牌和二维码。
- 背景可以生成人物，但人物必须来自文章语境，不得声称或暗示为用户本人的真实影像。

## 第一阶段：文章语境提炼

### 输入

```json
{
  "article_title": "门口的老槐树",
  "article_content": "文章正文",
  "quote": "那时候日子虽然苦，一家人在一起就觉得踏实。",
  "preferred_style": "warm_documentary | vintage_film | oriental_ink"
}
```

### 提炼提示词

```text
你是生命故事视觉编辑。请根据一篇中国家庭回忆文章及其中的一句金句，提炼适合生成分享卡背景的视觉信息。

只提取文章中明确出现或可以稳妥推断的内容，不虚构重大事件、人物关系、地点或年代。优先寻找最能解释金句含义的生活场景、环境和物件，不要只复述金句。

输出严格 JSON：
{
  "core_meaning": "金句在文章语境中的含义，20字以内",
  "era": "明确年代；无法确定则写泛化年代感",
  "location": "文章中的地点或场景",
  "event": "与金句直接相关的事件",
  "visual_elements": ["3至5个有画面感的物件或环境元素"],
  "emotion": ["1至3个情绪词"],
  "light": "适合该情绪的自然光线",
  "dominant_colors": ["2至4个低饱和色彩"],
  "people": [
    {
      "role": "文章明确的人物关系或身份",
      "action": "文章明确描述的动作",
      "appearance": "文章明确提供的年龄段、服装或外貌信息"
    }
  ],
  "avoid": ["与文章冲突或不应出现的元素"]
}

不要输出姓名、手机号、住址等个人隐私；不要摘录文章中的其他长句；不要输出 JSON 之外的解释。
```

## 第二阶段：背景生成

### 主提示词

```text
为中国长辈生命故事制作一张 3:4 竖版金句卡的无字背景。

金句：{{quote}}
金句在文章中的含义：{{core_meaning}}
时代氛围：{{era}}
故事地点：{{location}}
相关事件：{{event}}
关键画面元素：{{visual_elements}}
文章人物与动作：{{people}}
情绪：{{emotion}}
光线：{{light}}
主色：{{dominant_colors}}
视觉风格：{{style_description}}

请把故事语境转化为一个统一、真实、克制的生活场景，让背景自然呼应金句，而不是制作通用怀旧模板。优先表现文章中真实出现的环境、物件、季节、人物互动和光线；画面温暖、有生活质感、有适度年代感，但不过度破旧或悲情。

根据文章语境决定是否出现人物。如果金句与具体的人物关系、劳动、团聚、离别或日常动作有关，可以生成与文章描述一致的人物和互动场景；如果文章没有人物信息，不要为了热闹自行增加人物。

背景人物是故事场景的视觉演绎，不得声称或暗示为用户本人的真实影像。没有人物参考照片时，不要复制用户头像或刻意生成与用户头像相似的脸。人物应服务于故事叙事，不抢占金句主体。

构图要求：中部保留大面积低细节、低对比区域，用于叠加中文金句；左下头像区域保持干净，用于叠加真实头像和姓名；右下二维码区域保持干净，用于叠加品牌与二维码。人物和背景主体不得遮挡这些区域。

不要生成任何文字、字母、数字、Logo、水印、二维码或边框排版。
```

## 风格变量

### warm_documentary｜温暖纪实

```text
温暖纪实摄影，真实中国家庭生活质感，自然窗光，低饱和米色、木色和暖灰，细节可信，不摆拍，不做商业广告。
```

### vintage_film｜旧时光胶片

```text
保存良好的家庭胶片照片质感，轻微颗粒与柔和褪色，克制暗角，色彩自然，不做严重划痕、脏污或破损效果。
```

### oriental_ink｜东方水墨

```text
现代东方水墨与宣纸肌理，将文章中的真实地点、人物和物件转化为含蓄意象，大面积留白，灰绿与淡赭色，不过度古风。
```

## 负向提示词

```text
与文章无关的人物，冒充用户本人，复制用户头像，人物抢占画面主体，夸张面部特写，手部特写，错误年代物件，虚构地标，文字，汉字，英文字母，数字，Logo，水印，二维码，宣传标语，猎奇衰老，破败脏污，赛博霓虹，蓝紫科技感，商业广告，复杂拼贴，中心高对比主体，高频花纹，过度锐化。
```

## 输出建议

- 原型预览：768 × 1024 px。
- 正式分享：1080 × 1440 px。
- 输出无字背景图，由应用端叠加头像、金句、署名、品牌与二维码。
- 生成失败或超时时保留默认背景，保存和分享按钮始终可用。
