# 金句卡 AI 背景提示词

## 使用边界

- AI 只生成金句卡的背景，不处理、重绘或修复用户头像。
- 原始头像仅在端内做轻度居中裁切，保持本人真实面貌。
- 背景模型不发送头像、姓名、手机号或完整访谈原文，只接收抽象主题和情绪标签。

## 输入字段

```json
{
  "style": "warm_study | vintage_film | ink_memory",
  "story_title": "门口的老槐树",
  "story_theme": "童年、故乡、夏日乘凉",
  "emotion": "温暖、安静、怀念",
  "dominant_colors": "米白、木棕、低饱和橙",
  "aspect_ratio": "3:4"
}
```

## 固定主提示词

为一张中国长辈生命故事金句卡生成竖版背景画面，比例 3:4。主题为「{{story_theme}}」，情绪是「{{emotion}}」，主色为「{{dominant_colors}}」。画面温暖、真实、克制，有生活年代感和可触摸的材质细节。中部保留大面积低对比留白，确保深棕色中文金句清晰可读；左下头像区域保持干净、低细节；右下二维码区域保持干净、低细节。只生成环境、光影、物件或抽象氛围，不生成人物、面孔、手、身体，不生成文字、字母、数字、标识、水印或二维码。整体适合家庭纪念与长辈分享，不做商业广告感。

## 风格补充词

### warm_study｜暖光书房

中国家庭书房，木质桌面，旧相册一角，窗边柔和午后光，米白宣纸质感，低饱和暖棕，安静而亲切。

### vintage_film｜旧时光胶片

旧相纸与胶片颗粒，轻微褪色，克制暗角，低对比暖灰棕，细微划痕但保持干净，像保存良好的家庭老照片。

### ink_memory｜水墨记忆

现代东方水墨，宣纸肌理，远山、树影与旧屋的抽象轮廓，大面积留白，灰绿与淡赭色，清雅、含蓄、不过度古风。

## 负向提示词

不要人物、面孔、肖像、手、身体、文字、字母、数字、logo、水印、二维码；不要墓地、葬礼、医院、哭泣、衰老猎奇；不要赛博霓虹、蓝紫科技感、商业海报、拼贴、高对比、复杂中心主体、强烈锐化。

## 输出建议

- 原型预览：768 × 1024 px。
- 正式分享：1080 × 1440 px。
- 输出无字背景图，由客户端叠加头像、金句、署名、品牌与二维码。
- 失败或超时时保留默认背景，保存和分享按钮始终可用。
