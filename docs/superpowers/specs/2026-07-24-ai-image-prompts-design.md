# 云忆金句卡与半身人物形象提示词设计

日期：2026-07-24  
范围：金句卡 AI 背景、AI 半身人物形象，不包含模型接入与接口开发。

## 1. 目标与边界

### 金句卡背景

- 背景必须同时理解金句内容及其所在文章的语境，不能只套固定风格模板。
- 金句不设置字数上限，完整参与语境提炼；应用端根据实际长度自动换行排版。
- AI 只生成无字背景，不处理头像，不生成姓名、金句、品牌、二维码或其他文字。
- 应用端负责叠加金句、人物头像、署名、品牌和二维码。
- 不把手机号等无关个人信息发送给图片模型。

### 半身人物形象

- 使用用户上传的清晰半身照作为身份参考图。
- 脸部身份一致性是最高优先级；保留脸型、五官比例、年龄感、肤色与主要发型特征。
- 可以调整服装、姿态、背景、光影和整体风格，但不得美化成另一个人或明显年轻化。
- 输出为头部至腰部的 3:4 竖版人物形象。

## 2. 金句卡生成链路

采用两阶段生成：

1. 文本模型读取金句和所在文章，提炼时代、地点、事件、关键物件、自然环境、情绪与视觉隐喻。
2. 图片模型只接收提炼后的画面描述、金句与版式要求，根据文章语境生成可包含人物、但不含文字的背景。

不建议把完整文章直接交给图片模型。结构化提炼能减少隐私暴露，也能降低模型遗漏重点或生成无关场景的概率。

## 3. 金句卡语境提炼提示词

### 输入

```json
{
  "article_title": "门口的老槐树",
  "article_content": "文章正文",
  "quote": "那时候日子虽然苦，一家人在一起就觉得踏实。",
  "preferred_style": "warm_documentary | vintage_film | oriental_ink"
}
```

### 系统提示词

```text
你是生命故事视觉编辑。请根据一篇中国家庭回忆文章及其中的一句金句，提炼适合生成分享卡背景的视觉信息。

只提取文章中明确出现或可以稳妥推断的内容，不虚构重大事件、人物关系、地点或年代。优先寻找最能解释金句含义的生活场景、环境和物件，不要只复述金句。

输出严格 JSON：
{
  "core_meaning": "用一句简洁的话概括金句在文章语境中的含义，信息完整优先，不限制字数",
  "era": "明确年代；无法确定则写泛化年代感",
  "location": "文章中的地点或场景",
  "event": "与金句直接相关的事件",
  "visual_elements": ["3至5个有画面感的物件或环境元素"],
  "emotion": ["1至3个情绪词"],
  "light": "适合该情绪的自然光线",
  "dominant_colors": ["2至4个低饱和色彩"],
  "people": [
    {
      "role": "人物在故事中的关系或身份，如母亲、兄妹、邻里；未知则不填写",
      "action": "文章明确描述的动作",
      "appearance": "只使用文章明确提供的年龄段、服装或外貌信息"
    }
  ],
  "avoid": ["与文章冲突或不应出现的元素"]
}

不要输出姓名、手机号、住址等个人隐私；不要摘录文章中的其他长句；不要输出 JSON 之外的解释。
```

## 4. 金句卡背景生成提示词

### 主提示词

```text
为中国长辈生命故事制作一张 3:4 竖版金句卡的无字背景。

金句：{{quote}}
金句在文章中的含义：{{core_meaning}}
时代氛围：{{era}}
故事地点：{{location}}
相关事件：{{event}}
关键画面元素：{{visual_elements}}
情绪：{{emotion}}
光线：{{light}}
主色：{{dominant_colors}}
视觉风格：{{style_description}}

请把故事语境转化为一个统一、真实、克制的生活场景，让背景能够自然呼应金句，而不是制作通用怀旧模板。优先表现文章中真实出现的环境、物件、季节和光线；画面温暖、有生活质感、有适度年代感，但不过度破旧或悲情。

构图要求：中部保留大面积低细节、低对比区域，用于叠加中文金句；左下保留干净区域用于叠加真实头像和姓名；右下保留干净区域用于叠加品牌与二维码。背景主体不得压住这些区域。

根据文章语境决定是否出现人物。如果金句与具体的人物关系、劳动、团聚、离别或日常动作有关，可以生成与文章描述一致的人物和互动场景；如果文章没有人物信息，不要为了热闹自行增加人物。

背景人物是故事场景的视觉演绎，不得声称或暗示为用户本人的真实影像。没有人物参考照片时，不要复制用户头像或刻意生成与用户头像相似的脸。人物应服务于故事叙事，不抢占金句主体，也不得遮挡中部文字区、左下头像区和右下二维码区。

不要生成任何文字、字母、数字、Logo、水印、二维码或边框排版。
```

### 风格变量

`warm_documentary`：

```text
温暖纪实摄影，真实中国家庭生活质感，自然窗光，低饱和米色、木色和暖灰，细节可信，不摆拍，不做商业广告。
```

`vintage_film`：

```text
保存良好的家庭胶片照片质感，轻微颗粒与柔和褪色，克制暗角，色彩自然，不做严重划痕、脏污或破损效果。
```

`oriental_ink`：

```text
现代东方水墨与宣纸肌理，将文章中的真实地点和物件转化为含蓄意象，大面积留白，灰绿与淡赭色，不过度古风。
```

### 负向提示词

```text
与文章无关的人物，冒充用户本人，复制用户头像，人物抢占画面主体，夸张面部特写，手部特写，错误年代物件，虚构地标，文字，汉字，英文字母，数字，Logo，水印，二维码，宣传标语，猎奇衰老，破败脏污，赛博霓虹，蓝紫科技感，商业广告，复杂拼贴，中心高对比主体，高频花纹，过度锐化。
```

## 5. 半身人物形象提示词

### 输入

```json
{
  "reference_image": "用户上传的原始半身照",
  "style": "warm_life | elegant_oriental | vintage_memory",
  "gender_expression": "从参考图保持，不自行改变",
  "aspect_ratio": "3:4"
}
```

### 主提示词

```text
以所提供的参考照片为唯一人物身份依据，生成一张 3:4 竖版、头部至腰部的高质量半身人物形象。

最高优先级是保持本人身份一致：准确保留参考图中的脸型、五官结构与比例、眼睛形态、鼻型、嘴型、眉形、肤色、年龄特征、自然皱纹、主要发型与发际线。生成结果必须让本人及家人能够一眼认出是同一个人。

不要换脸，不要把人物年轻化，不要过度磨皮，不要改变性别表达，不要把五官调整成通用网红脸或陌生人的脸。可以在不改变身份的前提下，轻微改善光线、衣着整洁度和自然精神状态。

画面为自然放松的半身姿态，头部完整，肩部与上半身结构合理，双手如出现必须自然。人物是唯一视觉主体，背景简洁、温暖、低细节，为后续品牌海报排版保留空间。光线柔和真实，肤色自然，画面有家庭纪念价值，不做商业写真或夸张艺术照。

风格要求：{{style_description}}
```

### 风格变量

`warm_life`：

```text
温暖生活纪实风，简洁得体的日常服装，柔和自然窗光，米白与暖木色背景，亲切、真实、精神自然。
```

`elegant_oriental`：

```text
典雅现代东方风，材质自然、剪裁得体的中式服装，淡雅米色、茶褐与灰绿色背景，含蓄端庄，不过度古装化。
```

`vintage_memory`：

```text
克制的旧时光肖像风，参考中国家庭老照片的温暖胶片色彩，但保持现代清晰度与真实肤色，不添加破损、污渍或夸张年代道具。
```

### 负向提示词

```text
不同的人脸，身份漂移，改变脸型，改变五官比例，年轻化，老化，换性别，网红脸，欧美化五官，浓妆，过度磨皮，塑料皮肤，假笑，夸张表情，错误发型，错误发际线，眼睛不对称，牙齿异常，手指异常，肢体畸形，头部裁切，全身照，大头证件照，多人，文字，Logo，水印，二维码，商业影楼背景，赛博风，卡通化，低清晰度。
```

## 6. 模型参数建议

人物生成不能只依赖文字提示词，必须同时使用身份参考能力：

- 身份参考权重：建议从 `0.80–0.90` 开始测试。
- 风格强度：建议控制在 `0.25–0.40`，避免风格覆盖本人特征。
- 人脸修复：仅允许低强度修复，不启用强美颜或年龄重绘。
- 每次生成 2–4 张候选图，由用户主动选择确认。
- 如果身份一致性评分或人工检查不合格，结果不得进入“可设为头像”状态。

具体参数名称需根据最终选用的图片模型映射，不能把上述通用数值直接视为所有模型的固定参数。

## 7. 失败与安全处理

- 金句卡语境不足时，退回文章中已确认的地点、季节和物件，不虚构具体历史场景。
- 金句卡背景生成失败时使用默认背景，不阻断保存和分享。
- 半身照中人脸过小、遮挡严重、多人或模糊时，先提示重新上传，不直接生成。
- 人像生成后先展示预览；未经用户主动确认，不替换当前头像。
- 人物参考图不得用于训练、公开展示或生成与当前功能无关的内容。

## 8. 验收标准

- 金句卡背景能从画面中看出与文章语境的关联，而非仅有统一怀旧滤镜。
- 背景人物与文章中的关系、年代和动作一致；不冒充用户本人，也不抢占金句主体。
- 背景不含文字、标识和二维码，预留区域足够排版。
- 半身人物与参考照片为同一人，年龄、脸型和主要五官无明显漂移。
- 三种人物风格只改变表达方式，不改变人物身份。
- 任何人物生成结果都不会自动替换用户当前头像。
