# 云忆头像与 AI 金句卡轻量闭环设计

日期：2026-07-24  
范围：仅调整高保真原型 `prototype-v17.html`，不接入真实小程序后端或图片模型。

## 1. 目标

让用户首次进入时可以自愿上传一张头像，并让同一头像自然贯穿“我的”与金句卡，形成可感知的个性化闭环。金句卡背景体现“AI 正在为这句话配图”的能力，但人物保持用户上传的原始头像，仅做轻度裁切，不交给 AI 重绘。

验收结果：

1. 首次资料页可以上传或跳过头像。
2. 上传头像后，“我的”页和金句卡展示同一头像。
3. 未上传头像时继续使用姓名首字占位，不阻断主流程。
4. 金句卡覆盖 AI 背景生成中、成功、失败兜底和换一张四种体验。
5. 原型内附可交付后端的背景提示词契约，且明确不生成人物和文字。

## 2. 已确认决策

- 采用轻量闭环，不新增独立海报工作台。
- 头像允许跳过。
- 分享卡使用用户上传的原始头像，只做裁切和显示适配。
- AI 仅负责金句卡无人物、无文字的背景。
- 当前仓库只模拟 AI 生成状态，不声称已经接入真实模型。

## 3. 用户流程

### 3.1 首次进入

`欢迎页 → 基础信息页 → 可选头像 → 开启人生回忆`

基础信息页新增头像区，位于“这本书写谁”之后、“怎么称呼您”之前：

- 标题：`放一张您的照片`
- 说明：`以后做故事卡时会用到；不放也可以继续。`
- 主操作：`拍照 / 从相册选择`
- 次操作：`暂时不放`
- 已选择状态：显示圆角头像预览，并提供 `换一张`。

原型通过浏览器文件选择读取图片，裁切为居中方形预览。为保证页间状态，压缩后以 Data URL 存入 `localStorage`；仅用于本机原型演示。

### 3.2 我的页面

- 有头像：姓名左侧展示圆形裁切头像。
- 无头像：保留当前“兰”字占位。
- 点击头像或“资料”仍进入个人资料页。
- 个人资料页增加头像行，支持 `更换` 与 `移除`；移除后“我的”和金句卡同时回退到首字占位。

### 3.3 金句卡

金句卡调整为三层：

1. AI 背景层：无人物、无文字的气氛背景。
2. 内容可读层：暖色遮罩和纸感承载金句。
3. 身份层：头像、姓名、故事来源和二维码。

头像放在姓名左侧，尺寸不小于 56px；无头像时使用姓名首字。人物头像不得被 AI 风格化。

## 4. AI 背景状态

### 4.1 生成中

- 首次进入金句卡时显示轻量提示：`正在为这句话配一幅背景…`
- 背景区域使用柔和渐变与缓慢明暗变化，金句文字保持可读。
- 不使用孤立转圈，不遮挡保存与返回。

### 4.2 生成成功

- 原型从 3 个模拟背景中选取一个：`温暖书房`、`岁月胶片`、`东方水墨`。
- 显示轻提示：`背景已生成`。
- 提供 `换一张背景`，切换后重新经历短暂生成中状态。

### 4.3 生成失败

- 文案：`背景暂时没生成好，金句卡已经为您保留。`
- 使用当前暖米色纸张背景兜底。
- 提供 `再试一次`，失败不影响保存、分享或返回。

## 5. AI 背景提示词契约

### 5.1 输入变量

```json
{
  "style": "warm_study | vintage_film | ink_memory",
  "story_title": "门口的老槐树",
  "story_theme": "童年、故乡、家人、老物件等受控主题",
  "emotion": "温暖、怀念、平静等受控情绪",
  "dominant_colors": ["米色", "木色", "低饱和橙棕"],
  "aspect_ratio": "3:4"
}
```

不向图片模型发送用户姓名、手机号、完整故事原文或头像。

### 5.2 固定主提示词

```text
为一张中国长辈生命故事金句卡生成竖版背景画面。
主题：{{story_theme}}；情绪：{{emotion}}；风格：{{style_description}}。
画面需要温暖、真实、克制、有岁月感，主色为{{dominant_colors}}。
采用 3:4 竖版构图，中部保留大面积低细节留白供中文金句排版，
左下保留人物头像和姓名区域，右下保留二维码区域。
只生成环境、光影、物件和抽象氛围，不生成人物，不生成文字、字母、数字、标志或二维码。
背景不能抢夺文字注意力，避免高频纹理和强烈对比。
```

### 5.3 风格变量

`warm_study`：

```text
中国家庭书房，木质家具，旧相册与书页，柔和窗光，暖米色和木色，纪实摄影质感。
```

`vintage_film`：

```text
旧相纸、胶片颗粒、轻微褪色、柔和暗角，克制的年代摄影质感，不做破损脏污效果。
```

`ink_memory`：

```text
现代东方水墨与宣纸肌理，远山、树影或旧屋的含蓄意象，大面积留白，墨色低对比。
```

### 5.4 负面约束

```text
禁止人物、脸、手、身体、文字、汉字、英文字母、数字、Logo、水印、二维码；
禁止墓地、丧葬、病床、悲伤哭泣、诡异老化、过度怀旧滤镜；
禁止赛博霓虹、紫蓝渐变、强烈商业广告感、复杂拼贴和高对比花纹。
```

### 5.5 输出要求

- 预览尺寸：768 × 1024。
- 正式分享尺寸：1080 × 1440。
- 输出不含任何文字；文字、头像、品牌和二维码由应用程序最终合成。

## 6. 原型组件与状态边界

在单文件原型内保持小范围修改：

- `AvatarStore`：读取、保存、清除压缩后的头像 Data URL。
- `AvatarPicker`：首次资料页与个人资料页复用的选择、预览和移除逻辑。
- `syncAvatarViews()`：同步“我的”、个人资料和金句卡头像。
- `QuoteBackgroundMock`：模拟 `idle / generating / ready / failed`，支持换一张和重试。

正式产品接口边界预留为：

```text
POST /api/quote-card/backgrounds
GET  /api/quote-card/backgrounds/{jobId}
```

原型不发网络请求，只在界面和 PRD 面板中说明该契约。

## 7. 隐私与容错

- 头像采集必须明确可跳过。
- 原型说明头像用于个人资料和分享卡展示，不用于 AI 重绘。
- 头像读取失败时给出温和提示并保留首字占位。
- 超大图片在浏览器端压缩，避免 `localStorage` 超限。
- 移除头像后，所有页面立即回退到首字占位。
- AI 背景失败不得导致金句卡不可保存或分享。

## 8. 验证

### 功能状态

- 无头像进入资料页、“我的”和金句卡。
- 选择头像后跨页面同步。
- 更换头像后跨页面同步。
- 移除头像后全部回退。
- AI 背景生成中、成功、换一张、失败、重试。

### 渲染状态

至少重新渲染并查看：

- `setup`
- `mine`
- `profile`
- `quotecard` 无头像
- `quotecard` 有头像且背景生成完成
- `quotecard` 背景生成中
- `quotecard` 背景失败兜底

### 视觉验收

- 头像不变形、不被裁掉关键面部。
- 金句在三种背景上都清晰可读。
- 触控目标符合适老要求，关键按钮热区不小于 60px。
- 头像上传区不挤压现有基础信息，底部操作不遮挡内容。
- 页面保持当前暖色、纸感、低压力的产品方向。

## 9. 明确不做

- 不接入真实 AI 图片模型。
- 不上传真实用户数据到服务器。
- 不实现人物海报、多版本历史、收藏或付费。
- 不重构书房、讲述或成书主链路。
- 不让 AI 生成或修改用户头像。
