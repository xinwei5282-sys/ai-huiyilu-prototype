# 云忆回忆录开发交付设计稿

> 目标：把当前高保真 HTML 原型作为开发可用设计稿使用。视觉以 `prototype-v17.html` 为准，规则以本文件、`UI设计规范.md` 和原型右侧 PRD 面板共同约束。

## 1. 交付定位

当前原型不是低保真线框，而是开发可参考的高保真交互设计稿。

开发使用时按三类真源判断：

| 类型 | 真源 | 用途 |
|---|---|---|
| 页面与交互 | `prototype-v17.html` | 页面清单、跳转、点击状态、弹窗、异常演示 |
| 视觉规范 | `docs/UI设计规范.md` | 颜色、字号、圆角、按钮、卡片、状态色 |
| 产品规则 | 原型右侧 PRD 面板 | 页面目标、字段、异常、埋点、验收 |

如果三者冲突：

1. 先以 `UI设计规范.md` 和 PRD 面板为规则真源。
2. 再回修 `prototype-v17.html`，保持原型和规则一致。

### UI 图规范对齐

后续逐页调整时，原型样式按 UI 图规范收敛，不再为单页临时新增未命名颜色。

- 页面底色优先使用 `--cream`，浅卡片使用 `--cream-2` 或纸页渐变。
- 内容卡片使用 `--card` + `--paper-line`，避免厚重阴影和后台感边框。
- 标题使用 `--brown-h`，正文使用 `--text`，说明文字最低使用 `--text-2`。
- 陶土色 `--gold` / `--gold-deep` 只做少量强调，不做一页内多处强按钮。
- 松绿色只表达已保存、已完成、已采纳、安心继续。
- 关键正文不小于 16px，辅助文字不小于 14px；面向长辈的阅读页应继续放大。
- 每页调整后必须重新渲染对应 screen，截图验收无溢出、错位、遮挡。

## 2. 主链路页面

| 阶段 | Screen ID | 开发目标 |
|---|---|---|
| 认识对象 | `setup` | 采集被记录人基础信息，可跳过 |
| 开口讲述 | `session` | 支持问题式采访、随便讲、照片入口、语音/键盘输入 |
| 采访完成 | `session` 内 `ivRecordedPane` | 追问确认、跳过追问、直接看小结 |
| 故事成稿 | `summary` / `story` | 生成故事卡、编辑、自动保存、分享 |
| 进入书房 | `shelf` | 只展示已完成成果，章节书本是主视觉单位 |
| 书详情 | `book` | 整本书预览、目录、上传素材、协作、分享、纸质书 |
| 纸质成书 | `printbook` | 展示打印规格、翻页预览、PDF 生成入口 |

## 4. 组件拆分建议

| 组件 | 覆盖页面 | 开发要求 |
|---|---|---|
| `AppShell` | 全部手机页 | 状态栏、微信胶囊、屏幕容器、滚动区域 |
| `BottomTab` | `session` / `shelf` / `mine` | 3 Tab 固定，当前态一致 |
| `TopNav` | 二级页 | 返回、标题、右侧操作统一 |
| `PrimaryButton` | 全局 | 主按钮使用低饱和陶土色，热区不小于 44px |
| `StoryCard` | `summary` / `story` / `book` | 标题、正文、金句、图片、自动保存态 |
| `InterviewPanel` | `session` | 开场、录音、处理、追问、断网、权限失败 |
| `ChapterBook` | `shelf` | 章节书本，状态：已成稿 / 待补充 |
| `BookPreview` | `book` / `printbook` | 封面、目录、正文、照片页、翻页 |
| `ReviewItem` | `review` / `msgs` | 贡献者、摘要、状态、操作 |
| `EmptyState` | `shelf` / `msgs` / `contriblist` | 空态必须给下一步动作 |

## 5. 尺寸与响应验收

移动端优先验收宽度：

- 390px
- 414px
- 430px

验收规则：

- 关键按钮热区不小于 44px。
- 底部 Tab 不遮挡正文和主按钮。
- 长文本区域必须可滚动。
- 页面标题、按钮文字、卡片文字不得溢出。
- 关键正文不小于 16px，辅助文字不小于 14px。
- 书房页必须保持章节成果优先，不展示未完成任务压力。

## 6. 开发验收清单

- [ ] 屏幕地图中的每个 `screen id` 都有对应实现页面。
- [ ] 主链路 `setup -> session -> summary -> shelf -> book -> printbook` 可走通。
- [ ] 讲述页覆盖语音、键盘、暂停、处理中、追问、断网、权限失败。
- [ ] 故事页支持编辑和自动保存反馈。
- [ ] 书房只展示已完成成果，未完成内容不进书房。
- [ ] 书详情能进入上传素材、协作、分享、纸质书。
- [ ] 协作流程覆盖邀请、贡献、审核、采纳。
- [ ] 所有状态色符合 `UI设计规范.md`。
- [ ] 390 / 414 / 430 宽度下无明显遮挡、溢出、错位。
- [ ] 关键动作有埋点事件名或后续可补的事件位。

## 7. 暂不交付范围

- 正式小程序代码结构。
- 后端接口完整字段。
- 支付流程真实接入。
- PDF 真实生成服务。
- Figma 组件库。

这些可以在下一阶段从本原型反向整理。

1. 按本文件把开发任务拆成页面组件。
2. 给 `session`、`shelf`、`book` 三个 P0 页面先做组件级验收。
3. 再把其它页面按协作、账户、分享、纸质书分批实现。
