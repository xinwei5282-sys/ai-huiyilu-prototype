与个人 `memoir-film` 技能包采用相同阶段及确认原则，但尚未连到技能执行后端。本原型导出 JSON 的字段是前端制作包，不能直接充当 Python `pipeline.py` 的请求或真实服务审批凭证。正式接入需做字段映射、鉴权、不可变来源快照、独立事实审查、精确版本 hash 和服务回调幂等控制。

当前“本人确认”表示本机用户明确点击确认按钮，不是经服务端鉴权的审批。真实图像／语音／视频调用及发布授权沿用正式系统规则，不由本地确认自动获得。
