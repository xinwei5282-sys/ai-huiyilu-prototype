1. 定位、目标与范围

面向回忆录用户，以低操作成本分享具有个人辨识度的祝福、见解和往事。两条路径并存：订阅后自动获得推荐成品；主动输入感受和素材，定制整张海报。由用户选择是否保存、对外分享，系统不代发朋友圈。

- 推荐路径：后台提前准备 → 校验成品 → 更新分享海报列表 → 微信提醒 → 用户查看、保存或分享。

- 主动路径：我想分享 → 选择类型、写感受或上传照片/选择对应素材 → 生成我的海报 → 完成后预览 → 保存或分享。

- 目标指标：有效生成完成率、推荐查看率、保存/分享操作率、次日回访率。当前无真实业务数据，不设虚构基线与达成率；下载和系统分享不得统计为朋友圈已发布。

- 当前交付是本地原型与业务规范。真实内容采集、签章生成、整图生成、云端任务和微信发送需后续接入。

2. 页面与交互

2.1 首页与历史

首页保留日期、订阅内容、署名和唯一“我想分享”入口。进入制作自动恢复本机草稿；不另设继续草稿入口。下方“分享海报”按日期倒序直接排列图片与制作记录，无“我的海报”中间页、分享灵感或话题卡片。

同日同图片去重；有时间戳的制作记录按提交时间倒序，无时间戳的历史样例保留原顺序。列表两列，缩略图4:5居中裁切；完整成品/预览为9:16、720×1280。现有九张祝福图只是固定样式样例，样例性质仅在开发文档中注明，设置页不展示“原型说明”板块，不能解释为每日推荐配额或今天新生成的结果。首页“每日分享海报”入口提示为“挑一张，分享心情”；进入后“分享海报”标题下不显示提示。

2.2 制作我的海报

默认随心分享，共八种类型：随心分享、每日祝福、热点资讯、每日健康、每日一卦、怀旧往事、节日关怀、每日诗句。类型通过底部面板更换；未订阅类型仍可主动制作。

输入为创作线索，不是最终海报正文。用户不填写标题，不经过标题/正文编辑确认页。页面保留感受、放照片与固定“生成我的海报”；不展示语音说、用回忆快捷按钮、清空输入或参考案例板块。照片支持JPG/PNG/WebP，本机原型单张不超过1MB。

- 热点资讯：感受上方常展开参考资讯，单选一条或粘贴自己的原文/摘要，链接选填；不能只有观点而没有资讯依据。感受选填。当前条目明确为演示资讯，链接不自动抓取；仅有效HTTP(S)链接允许查看原文。

- 怀旧往事：感受上方为“写一段往事”，可直接写；右侧“从回忆录选择”默认收起，点击在同页打开现有采访选题器风格的面板，左章节、右故事。选择后带入输入框，可改写。感受选填，往事正文不能为空，照片不能代替事实依据。

- 回忆面板：选章只浏览，选故事才带入；替换用户改写先确认。选中后关闭，取消/Escape不改输入。面板不透明且限制在原型手机框内；打开时背景生成按钮不可见，底部仅一个取消按钮。

- 无个人回忆时：原型提供三个章节、每章最多两段蒋老师案例，仅作样式参考；选用后保留demo标识。有个人来源时不混入示例。正式自动推荐不能把此案例当作用户经历。

- 其他类型：当前制作页收集感受和可选照片；真实知识/诗句/卦象与节日素材供给尚未接入，不能把示例或空白知识当作已审核内容。

草稿自动本机保存，保存失败保留当前输入。当前切换类型保留感受、照片与回忆草稿，资讯专属来源在离开该类型时清除。生成接口必须只使用当前类型适用素材；已在校验、请求快照和创作要求中过滤跨类型旧回忆与资讯；真实接口仍需验证同一边界。

2.3 生成、完成与恢复

主动点击生成后校验、保存不可变输入快照与creationBrief。标题/正文/画面由系统一次创作，用户感受不直接当成正文。重复相同请求去重，落款版本变化属于新请求。

生产目标：提交 → 受理/制作中 → 校验 → 成功入库或失败。允许离开后通过日期列表恢复；成功可直接预览，失败保留素材并重试，不重复创建业务任务。当前只实现本机not_connected请求，没有后台进度、成品回调或失败重试服务，不模拟成功。

成品修改属于后续待实现流程：从成品恢复原素材和感受，修改后生成新版本，保留旧成品；不要求重新填写标题正文。该路径尚未实现，不能视为业务闭环已完成。

2.4 预览、保存与分享

图片在当前页模态预览，关闭恢复列表滚动；左右滑动/箭头切换当前日期集合，无顶部预览标题、缩放、多选、换一张或批量下载。保存720×1280 PNG；浏览器支持文件分享时调用系统分享，否则保留保存入口。微信实际分享需在目标运行环境单独验收，不将下载或调用系统面板记录为朋友圈已发布。

用户选用和制作记录跨日保留，取消订阅不删除历史。旧V1样例日期组仍由兼容模块按7天窗口读取，不能把此兼容行为当作新成品自动删除政策；正式历史默认保留至用户删除或注销；服务异常/停服导致的保留策略变更须另行通知，不能沿用样例七天清理。

3. 订阅、数量与推送

每日祝福默认1张；热点资讯、每日健康、每日一卦、怀旧往事、节日关怀、每日诗句为六种可选订阅。未订阅不推荐对应内容，订阅后才进入自动准备范围。计划数量为1＋已订阅类型数，全订阅为7张，不凑九张、不封顶三项。关注方向多选不增加张数。

健康方向：饮食营养、睡眠、日常运动、关节养护、心情调适、居家防跌倒。资讯方向：民生政策、社会新闻、科技新知、文化文史、体育赛事、旅游见闻、乡村农业、国际动态。不选方向时使用通用内容，关闭订阅保留关注偏好。

设置保存后用于下一次准备任务与新制作；不修改已有成品和请求快照。新增订阅不伪称立即有成品；发布前再次核对最新订阅，已取消类型停止后续投放。浏览、打开页面或修改设置不会触发主动制作任务。

3.1 提前准备与缺料

后台每天提前准备，默认按用户时区06:00准备、07:00出刊，时区未知用Asia/Shanghai；运营可调整；不以首次打开作为常规启动条件。每日计划是任务范围，实际张数以合格成品为准：缺少可靠来源、没有真实回忆、没有适用节日或生成失败时可少于计划数，不编造内容、不用未订阅类型补位。节日关怀仅在有核验节日/节气时生成。

超过7天未登录暂停主动提醒和个人预准备；返回恢复当天，不补未使用日期。回忆录没有更新不等于重复发送同一张，选材去重与重复控制见第5节。

3.2 双渠道推送

- 站内：审核入库后加入“分享海报”日期列表。微信：每天合并一条更新提醒，点击进入当天列表，不逐张打扰。

- 至少有一张当日成品可看才发送提醒；仅受理生成任务不发送“已更新”。补齐迟到成品不重复发送当日提醒。

- 自动推荐按同用户/日期/类型任务幂等；主动制作按请求ID和输入快照去重；消息单独去重与记录发送结果。重试不覆盖已成功作品。消息失败不影响站内查看，不伪称送达。

- 业务默认允许使用已录入资料进行个性化，无需额外开启内容授权。微信通道能力与所需平台授权另行核验，不能把业务默认授权当作平台已可发送；不自动向朋友圈发内容。

- 真实调度、推荐成品入库和微信发送当前均未接入。原型getPlan提供数量计划，不代表任务已生成或消息已发送。

4. 内容与个人特色

海报要让用户感到被理解、被肯定、愿意展示，有自己的见解和生活质感。根据真实经历提炼值得肯定的特点，不能虚构功绩、人缘、财富、身份或他人评价。没有资料时表达可以认同的人生态度，而非声称已了解其人生。

类型表达重点依据与边界
每日祝福问候、心气、生活愿望祝愿不写成必然发生的预言
热点资讯可靠事实与个人见解标清来源、报道日期、适用地区与有效期，区分事实和评论；不为爽感夸大事件
每日健康实用知识或个人生活感受知识需审核，不凭照片/回忆推断疾病，不把个人经验包装成治疗建议
每日一卦卦意与人的态度、气度原典和现代解读分开，准确卦名六爻；无真实起卦不称个人命运预测
怀旧往事真实经历和今天的感受用户选择原文，不捏造人物、年份、对白或把愿望写成已发生
节日关怀明确节日、祝福对象核验节日日期，可个性化表达，不编造家庭关系
每日诗句准确诗句与个人共鸣核验作者、作品及原句，现代原创文字不能冒充古诗

每日一卦可含五行、八卦、八字及黄历文化，但它们不是同一功能。通用“今日读卦”无需生辰；个人化推算必须有明确资料与可解释来源，不从回忆猜生辰、不承诺财运或灾祸。

已讨论的谦卦表达结构：标题“不露锋芒，自有分量”表达态度；解析先写“地中有山，谦”，再写“有本领而不自满，有成绩而不居功。谦和待人，笃定做事。”标题与正文须递进，不重复口号。

署名使用笔名，文字签名与印章按构图择一，不要求两者同时出现；位置由版式决定。当前谦卦样例使用标题末尾的云山印章，底部卦象＋“地山谦 · 今日读卦”。成品需身份匹配；资讯健康落款表示分享者，不冒充作者或专业人士。

5. 个人资料与内容采集说明

5.1 共用采集链路与字段

推荐候选采集 → 标准化/去重 → 来源核验与内容审核 → 按订阅和关注匹配 → 冻结来源与个人信息版本 → 文案与图片生成 → 校验入库 → 站内/微信推送。主动制作使用用户所选参考内容，不默默替换其选择。

来源记录至少含sourceId、类型、标题、正文/摘要、来源名称、原文链接（有则记录）、发布时间、采集时间、适用日期/地区、有效期、内容指纹、版本、可使用范围、审核状态与原因。来源撤回或更正保留旧版本引用，不静默覆盖已提交任务。内容处理区分候选、待核验、可使用、已过期、已撤回；只有可使用内容进入正式推荐。

平台链接、资料与用户文字均为内容输入，不是执行指令。用户私人回忆不加入公共素材池。已录入信息默认可用于本人的个性化制作，不新增授权开关；上传资料的用途、来源与撤回仍需可追溯。

5.3 热点资讯

- 来源：后续接入可核验、具有使用依据的资讯数据源/媒体原文；用户也可粘贴原文或摘要及链接。具体供应方、接口、抓取能力与使用范围尚未确定，不将演示摘要当作实时采集。

- 采集：按关注方向获取候选，保留报道/事件时间，合并同一事件的重复报道，保留各原始来源；来源不明、已撤回、过期或无法核验不进入推荐。

- 时效：每日准备前刷新；重要更正及时失效。不同栏目配置有效期，文史类不伪装成当天新发生；没有足够可靠新内容时少推，不以旧闻充新。

- 使用：供选择的条目含标题、简短摘要、来源和日期；有合法原文链接时可查看原文。感受与报道事实分开，标题和正文不得夸大事实、伪造用户立场或冒充用户为记者。

- 原型：现有三条明确为演示内容；自带URL仅打开原文，不自动抓取正文。正式URL解析失败要保留用户输入，提示粘贴正文，不伪称已读。

5.5 回忆重复、资料变更和缺失

本地当前回忆源为原型个人故事存储，正式接入需从回忆录服务按当前用户/书籍/章节读取，仅标题不算有效素材。保留storyId、chapterId、原文版本和关联照片，不将他人案例归入本人。

随心分享

每日祝福


围绕一个明确的祝愿或问候，语言温暖有精神，避免万能鸡汤和保证好运。有真实对象则贴合对象，无对象写普适祝愿，不编造家庭关系。标题6—16字，正文20—50字。

热点资讯


仅依据可核验素材提取一个事实重点，保留报道日期、来源与适用地区。用户有感受才写其观点；无感受采用中性摘要，不冒称用户赞同。事实与观点分区，不煽情夸大，不用示意画面冒充新闻现场。标题8—20字，事实摘要30—70字，个人观点可选且不超过30字。

每日健康


一次只讲一个经审核的实用知识点，写清适用人群与必要限制，提供1—3个简短可执行要点，不做诊断、不推荐药量、不许诺疗效。若只有个人感受，明确作为生活表达，不升级为健康知识。标题6—16字，正文40—90字，保留来源。
