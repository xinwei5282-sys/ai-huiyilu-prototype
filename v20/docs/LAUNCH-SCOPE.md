# 夸一夸首发开发范围

## 产品决策

在现有回忆录产品上增加一个独立的照片夸夸能力。夸夸面向所有年龄，使用时不要求创建回忆录；现有回忆录流程与已定业务规则继续生效。默认入口保留讲述，推广夸夸可直接打开夸夸页。

| 功能 | 首发行为 | 复用范围 |
|---|---|---|
| 入口 | 四个 Tab：夸一夸、讲述、书房、我的；夸夸支持直接进入 | 现有导航和登录身份 |
| 夸夸输入 | 一张照片+一句话必填；显示读取/生成/失败反馈，失败保留输入 | 现有媒体上传、鉴权、内容检查 |
| 生成 | 基于照片和用户文字，给出具体、自然、不过度的正向回应 | 现有模型网关，新增夸夸提示词及多模态调用 |
| 结果和收藏 | 夸夸文案、照片、收藏、保存分享卡 | 现有卡片渲染/下载/微信分享能力；新增夸夸记录类型 |
| 记录 | 我的 → 夸夸记录 → 详情；独立于故事/章节 | 现有账号；独立业务记录，不调用创建章节接口 |
| 共享知识 | 同一知识服务；按账号、被记录人、来源和授权过滤 | 现有资料与原始讲述存储；新增用途授权字段 |

## 共用知识库的最小边界

数据对象区分 `praise_record`、`memoir_story` 与 `source_material`。同库不意味着同一业务表或不加区分地检索。

- 夸夸记录保存 `user_id, subject_id, photo_asset_id, original_text, generated_text, referenced_source_ids, created_at`。
- 回忆录继续沿用原故事、章节和成书对象，夸夸不调用其创建/扣题量接口。
- 检索只允许同一账号权限内、属于当前人物、用户已确认、用途授权有效的原文。亲友记录、未采纳补录、AI 生成摘要不得直接作为本人事实。
- 回忆预览收录时可勾选授权原文；夸夸收藏时可勾选授权配文。两个勾选默认关闭。
- 原文保留来源和人物归属，生成内容不回灌为事实。无资料或未授权时，直接用本次照片与配文生成。
- 撤销后停止未来检索；已生成历史卡片不自动重写。
- 正式权限由服务端校验，不能依赖客户端传来的 `subject_id` 或勾选状态。

## 生成约束

只夸照片可见的努力、作品细节、搭配、情绪表达或用户明确描述的经历；不要从长相推断年龄、健康、财富、身份、性格或社会关系。引用记忆时保留来源，不将家人的经历转述成用户经历。不强制转去讲述、不自动成书。

## 本轮暂缓

新的会员/积分系统、广场、关注关系、复杂风格选项、全新首页、全产品换肤、完整知识库后台。夸夸计费策略另行确定，本次不改回忆录套餐或题量规则。

## 上线验收

先验证真实图片+配文的生成质量、失败重试、记录持久化、人物与用途权限、微信分享/相册权限、原回忆录关键流程回归。具体工期取决于现有模型网关和后端接口状态，本原型不代表已完成这些服务接入。

## 当前交付边界

本次为可交互 HTML 原型：选图、收藏、授权和 PNG 导出可以本机操作；生成采用演示文案，知识检索采用本地关键词匹配。共用回忆录原文的演示读自原版 `ivSaidText()`，只在用户勾选并收录时进入演示授权记录。没有接入真实 AI、后端或正式小程序；原回忆录的既有演示状态也不等于真实后端行为。新增存储仅使用 `yunyi.praise.v20`，不改原回忆录存储键。
